## Cross-Cutting Rules for Every Ticket

| Area | Rule |
|------|------|
| Multi-tenant | Semua query business data wajib filter `organization_id` |
| Delete | Jangan hard delete business data; gunakan soft delete |
| Backend response | Gunakan helper `response.*` untuk endpoint aplikasi |
| Frontend API | Semua call API harus lewat `src/services/` |
| TypeScript | Jangan gunakan `any` |
| Auth | Jangan simpan credential di query string/log |
| RBAC | Permission guard harus diuji minimal untuk role admin dan non-admin |
| Docs | Update dokumen jika kontrak API, workflow, entity, atau permission berubah |
| KPI | Setiap KPI wajib punya definition, unit, period, owner, source, formula, dan validation rule |
| Snapshot | Published report/health snapshot immutable; koreksi membuat version baru |
| Health | Gunakan `GREEN`, `YELLOW`, `RED`, `CRITICAL`; formula configurable/versioned, bukan hardcoded tanpa approval |
| Analytics/BI | Power BI/read model read-only terhadap operational store; RLS dan metric reconciliation wajib |
| Mockup | Nilai, nama, dan tanggal pada materi hanya ilustrasi, bukan seed/data produksi |
| Next.js runtime | Jangan jalankan `next dev` dan `next build` bersamaan pada `frontend/.next`; UI baru wajib CSS asset check dan screenshot multi-viewport |
